Paramètres Paiements Mobile

Configurez le numéro Huri Money qui reçoit les recettes de chaque type de paiement

Chaque type de paiement (amendes, vignette) peut être associé à un numéro Huri Money distinct, pour éviter de mélanger les recettes. L'intégration Huri Money est actuellement en mode simulation — ces numéros seront utilisés dès que les identifiants API réels seront configurés, et sont déjà enregistrés sur chaque paiement à titre de traçabilité.
Pour des raisons de sécurité, tout changement de numéro doit être confirmé par un code envoyé par email à une adresse fixe configurée côté serveur (non modifiable depuis cette page). Le changement n'est appliqué qu'après saisie du bon code.
